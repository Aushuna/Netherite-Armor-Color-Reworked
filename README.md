# Netherite-Armor-Color-Reworked

Netherite Armor Color Reworked is a Minecraft mod that adds 9 colored Netherite sets based on the ore block available in the game.

### Smithing table



S = Smithing tablet

N = netherite armor piece  

O = ore


### Smithing table recipie (add color)

S N O = Colored Netherite Armor
